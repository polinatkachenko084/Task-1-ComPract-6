# Task-1-ComPract-6

Програма для визначення оптимального місця розташування АТС (автоматичної телефонної станції) серед будинків.

## Опис задачі

Є вулиця з "n" будинків (n ≤ 10).  
У кожному будинку знаходиться певна кількість телефонів.  
Потрібно знайти такий будинок, у якому найвигідніше розмістити АТС, щоб сумарна довжина кабелів була мінімальною.
